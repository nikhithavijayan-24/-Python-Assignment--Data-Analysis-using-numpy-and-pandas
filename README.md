# Python DA Assignment 1 – Data Analysis Using NumPy and Pandas

## 📌 Project Overview

This project focuses on learning and applying fundamental Python data analysis techniques using **NumPy** and **Pandas**. The assignment covers numerical computations, array manipulation, Series operations, and DataFrame analysis.

## 🎯 Objectives

- Understand NumPy arrays and their properties.
- Perform numerical calculations and array slicing.
- Create and manipulate Pandas Series.
- Explore and analyze structured data using Pandas DataFrames.
- Apply filtering, indexing, grouping, and data manipulation techniques.

## 🛠️ Technologies Used

- **Python**
- **NumPy** – Numerical computing and array operations
- **Pandas** – Data manipulation and analysis
- **Jupyter Notebook** – Interactive coding and execution

## 📂 Topics Covered

### 1. NumPy Array Operations

- Creating one-dimensional and two-dimensional arrays
- Inspecting array shape, data type, and size
- Converting temperatures from Celsius to Fahrenheit
- Calculating maximum, minimum, and mean values
- Array indexing and slicing
- Extracting weekly and weekend temperature data

### 2. Pandas Series

- Creating a Series with custom indices
- Accessing values using integer positions, `loc`, and `iloc`
- Filtering values using Boolean masks
- Modifying and removing Series elements
- Calculating CGPA from marks

### 3. Pandas DataFrame

- Creating a transaction dataset
- Exploring data using `head()`, `tail()`, `shape`, and `dtypes`
- Selecting rows and columns using `iloc` and `loc`
- Filtering data using multiple conditions
- Finding value counts and unique values
- Grouping data by region and calculating mean amounts
- Updating values and creating a Discount column
- Removing rows and deleting columns

## 📊 Key Learning Outcomes

Through this assignment, I practiced essential data analysis operations and strengthened my understanding of working with numerical arrays and tabular datasets in Python.
